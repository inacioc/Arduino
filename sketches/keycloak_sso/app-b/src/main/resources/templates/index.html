The two ways in

Path Filter chain Credential Required role
/ui/** browser chain (order 2) session cookie from oauth2Login app-b-user
/api/** API chain (order 1), stateless Authorization: Bearer <JWT> app-b-api-reader or app-b-user

The API chain is declared first on purpose. If the browser chain matched /api/** first, an API call with a bad token would get a 302 redirect to the login page instead of an honest 401.
